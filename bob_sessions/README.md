# IBM Bob Session Evidence

This directory stores IBM Bob session reports, screenshots, and task histories
for the ReleaseShield hackathon demonstration.

## Contents

After running the full demo workflow with Bob IDE visible:

- `session-001/` — Initial impact analysis session
- `session-002/` — Multi-file remediation session  
- `session-003/` — Verification and repair session

## Recording Instructions

1. Open IBM Bob IDE
2. Set workspace to `demo-repo/`
3. Switch to `release-shield` mode
4. Run each step of the workflow
5. Export the task report from Bob IDE
6. Save as `bob_sessions/session-NNN/report.md` + screenshot

## Hackathon Evidence Requirements

Per hackathon rules, preserve:
- Task session reports showing Bob reasoning
- Screenshots of Bob IDE with workspace visible
- Evidence of multi-file edits
- Evidence of test execution through Bob
